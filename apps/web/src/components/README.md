# apps/web/src/components

**What's here:** React components grouped by area; each subfolder has its own README.
**Open this when:** building UI.

**Key files**

- `analytics/`: circle charts, payments heatmap, portfolio totals (own README)
- `app/`: app shell, page header, pagination, countdown, deadline, stat card, circle switcher, `TxFor`
- `exits/`: leaving a circle, guardian pause banner and button, refused-payout withdraw (own README)
- `governance/`: circle proposals, new-proposal dialog, rule-change and dissolve notices, rules card (own README)
- `art/`: cut-paper art, avatars, circle covers, empty-state scenes
- `kit/`: interaction kit (ADR 0026)
- `login/`: sign-in screen and return-path guard
- `public/`: public-site header, footer, content blocks
- `pwa/`: service-worker registration
- `ui/`: shadcn primitives restyled to Gallery
- `wallet/`: Core Wallet hooks, connect button, wallet gate
- `providers.tsx`: wagmi + TanStack Query providers
