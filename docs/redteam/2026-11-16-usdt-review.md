## Measurements behind `SETTLE_GAS`

Settle cost before the payout, `forge test --isolate` (every slot cold), 24-byte display names: creator first ~121k (includes retiring the guardian), later exits in the same batch ~62k. With 4-byte names: ~114k and ~56k. `SETTLE_GAS = 140_000` leaves ~15k over the lowest value the sweep passes with (125k), enough for a waiting flag (`exitsWaiting` write).
