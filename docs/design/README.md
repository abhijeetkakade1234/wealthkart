# docs/design

**What's here:** the locked visual identity and the reference behind it.
**Open this when:** building UI, briefing the illustrator, or checking how something should look.

| File                       | Purpose                                                                                                                                                                                                                              |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `gallery.html`             | **Locked look (ADR 0025): Gallery.** Calm, premium, light interface with folk-art illustration as the only loud element. Open in a browser (fonts load from Google Fonts). Online: https://claude.ai/artifact/NMfMgpLUAgh3owLM9iQLcu |
| `reference-paper-folk.png` | The founder's reference: cut-paper folk illustration and its palette. Use it to brief the illustrator.                                                                                                                               |
| `illustrator-brief.md`     | Brief for the illustrator: 1 hero + 20–30 cut-paper SVG pieces, palette, file specs, ownership, timeline. Placeholders live in `apps/web/src/components/art`                                                                         |

Rejected explorations (dark glow cards, material themes, the full folk-art UI) were removed after the decision; they're in git history and summarised in ADR 0025.
