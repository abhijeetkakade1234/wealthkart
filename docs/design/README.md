# docs/design

**What's here:** visual design explorations: colour, type and look directions for the app.
**Open this when:** choosing or revisiting the app's visual identity.

| File                       | Purpose                                                                                                                                                                                                                                                                                                               |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gallery.html`             | **LOCKED (ADR 0025): Gallery.** Calm, premium, light interface (Instrument Serif + Hanken Grotesk, near-monochrome, cobalt accent, generous whitespace) with folk-art illustration as the only loud element (hero, circle covers, empty states). Online: https://claude.ai/artifact/NMfMgpLUAgh3owLM9iQLcu            |
| `paper-folk.html`          | Rejected: Paper Folk, the whole UI in folk colours. Founder liked the illustration, not a playful UI. Cut-paper folk-art look from the founder's reference: desktop + phone mock, components, palette, type, paper and night modes. Online: https://claude.ai/artifact/NMfMgpLUAgh3owLM9iQLcu                         |
| `reference-paper-folk.png` | The reference the founder liked (a records label site with cut-paper illustration and its palette)                                                                                                                                                                                                                    |
| `look-directions.html`     | Round 2: five directions (Terminal, Thermal Receipt, Snowfield, Riso Print, Ledger Pad) on the same mock screen. Round 1 (four dark glow-card palettes) was rejected as too generic. Open in a browser; fonts load from Google Fonts (needs internet). Online copy: https://claude.ai/artifact/NMfMgpLUAgh3owLM9iQLcu |

Once a direction is picked, it's recorded as an ADR and turned into theme tokens in `apps/web`.
