Spacing

Empty space is the premium signal. Spacing runs on an 8px scale and leans generous: sections 160–180px apart, page padding 40px, cards 26–32px inside, table rows 18px. When something feels crowded, the fix is more space, not smaller text.

Where the illustration lives

  • Landing hero: one large piece (friends' hands, a shared pot, coins, the mountain).
  • Circle covers: each circle gets its own small composition, picked from a set of cut-paper pieces using the circle's address, so every circle looks unique.
  • Phone home, onboarding and empty states: small spot illustrations.
  • Member avatars: tiny cut-paper shapes generated from the wallet address.
  • Never inside tables, forms or anything you read to make a money decision.
About the artwork: the drawings here are my SVG stand-ins to show placement and colour. For launch, the hero and the cut-paper piece set should be drawn by an illustrator in this folk style (a commission of roughly 1 hero + 20–30 small pieces). The interface around them is final-quality.
