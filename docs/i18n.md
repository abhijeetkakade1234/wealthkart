# Languages: English, Hindi, Marathi

How the app speaks Hindi and Marathi, how to add or change a string, and the words we chose. Decision record: [ADR 0057](decisions/0057-hindi-and-marathi.md).

> **Review before mainnet.** Every Hindi and Marathi string was written by the team, not by a native-speaker reviewer. A native speaker of each language must read the app and the localized public pages before the mainnet launch (tracked in `TODO.md`). Fix wording in the dictionaries; keys and `{params}` stay.

## 1. How it works

- Code: `apps/web/src/i18n/`. English (`en/`) is the source of truth. `hi/` and `mr/` have the same files and the same keys.
- One file per area (namespace): `common`, `nav`, `time`, `msg` (the message catalogue), `kit`, `wallet`, `login`, `home`, `settings`, `reminders`, `checklist`, `circle`, `pay`, `create`, `rules`, `analytics`, `activity`, `record`, `join`, `membership`, `exits`, `nominee`, `loans`, `votes`, `site` (public page header and footer).
- English is bundled with the app. Hindi and Marathi are loaded with `import()` only when chosen, so English users don't download them.
- The choice is saved on the device (`localStorage` key `wk.locale`). With no saved choice the app uses the browser language if it is Hindi or Marathi, else English. `<html lang>` follows the choice.
- Switch: the language menu in the app header and on the sign-in page, the Language card in Settings, and the language links in the public footer.
- Public pages: `/`, `/start` and `/how-it-works` also exist as static pages at `/hi/...` and `/mr/...` with `hreflang` links. Their copy is in `src/content/hi/` and `src/content/mr/`. FAQ, rules, security and the legal pages are English only; the localized footer says the English legal text is the one that counts.

## 2. Adding or changing a string

1. Add the key to `en/<namespace>.ts`. Use `{name}` for values: `"Paid {amount} {symbol}"`.
2. Add the same key to `hi/<namespace>.ts` and `mr/<namespace>.ts`. Typecheck fails if a key is missing or extra; `i18n.test.ts` fails if the `{params}` or `<tags>` differ, a value is empty, or a value is the key itself.
3. Use it:
   - In a component: `const { t, tn, formatDate, formatNumber } = useT();` then `t("pay.title")`, `t("pay.paid", { amount, symbol })`.
   - Outside React (lib code, `messages.ts`): `import { t } from "@/i18n/runtime"`. It reads the active language at call time.
   - Plurals: keys `x_one` and `x_other`, then `tn("time.days", n)`. `{count}` is filled in. Hindi counts 0 as "one".
   - A link or bold word inside a sentence: put tags in the string (`"Read the <link>guide</link>"`) and render with `rich(t("..."), { link: (c) => <Link href="/start/">{c}</Link> })`. Every language must use the same tags.
   - A label kept in a constant: store the key (type `PlainKey`), call `t(key)` when rendering.
4. Dates: `formatDate(date, { day: "numeric", month: "short", timeZone: "UTC" })`. Numbers: `formatNumber(n)`. Hindi and Marathi use `hi-IN` / `mr-IN`, which group big numbers in lakh and crore. Money still goes through `src/lib/asset.ts`: amounts stay in AVAX or USDT, never converted to rupees.
5. Outside the core namespaces (`common`, `nav`, `time`, `msg`, `kit`, `wallet`), a file that uses a key must import its English namespace: `import "@/i18n/en/loans";`. That ships the words with the screen instead of in every page (bundle budget, ADR 0057); `i18n-imports.test.ts` fails if the import is missing.
6. Never hard-code English in `/app`, `/login` or the checklist. `messages.ts` keeps its function names and error codes; only the text moved to `msg`.

## 3. Writing rules

- Natural, simple, everyday words a non-crypto person uses. Not word-for-word, not heavily Sanskritised. Short sentences, same plain style as English (`docs/ui.md` §12).
- Keep as is: WealthKart, AVAX, USDT, Core, Avalanche, Fuji, Snowtrace, UTC, Chainlink. Write "wallet" and "app" as वॉलेट and ॲप/ऐप (see glossary).
- Explain a crypto word once where it first matters, then use the short word.
- Never advertise returns in any language (ADR 0024). The banned word list for public copy, with Hindi and Marathi equivalents, is in `apps/web/src/i18n/__tests__/i18n.test.ts`.
- No emojis. Digits stay Latin (0-9).
- Hindi and Marathi words run longer. Let text wrap; don't shrink it. Generous whitespace still applies (ADR 0025).

## 5. What is not translated

- Push reminders: the text is built in the indexer Worker and stays English for now (ADR 0057).
- `/faq`, `/rules`, `/security`, `/privacy`, `/terms`, `/risks`, `llms.txt`, `.md` twins, JSON-LD on English pages and the `/kit` dev showcase.
- Technical "Details" under an error (wallet and node messages) stay as the wallet sent them.
- Names people chose for circles and themselves.
